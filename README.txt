缩绒客户管理系统 - 使用说明
====================================

【一、直接运行（需要Python环境）】
  1. 安装 Python 3.8 或更高版本
  2. 双击 install_deps.bat 安装依赖
  3. 双击 run_server.bat 启动程序
  4. 浏览器访问 http://127.0.0.1:5000

【二、打包为独立EXE（推荐）】
  1. 在 Windows 电脑上安装 Python 3.8+
  2. 将整个文件夹复制到 Windows
  3. 双击 build_exe.bat
  4. 等待打包完成（约2-5分钟）
  5. 在 dist 文件夹中找到 "缩绒客户管理系统.exe"
  6. 把 exe 文件复制到任何地方即可使用

【三、使用打包好的exe】
  - 双击 exe 文件启动
  - 程序自动打开浏览器
  - 关闭命令行窗口即可停止服务
  - 数据库保存在 exe 同目录下的 suorong.db

【注意事项】
  - 首次启动如被杀毒软件拦截，请选择"允许运行"
  - exe 文件可放在桌面或任何文件夹
  - 数据都保存在 suorong.db 中，备份此文件即可备份数据
  - 如需导入Excel更新数据，启动后在网页中操作"导入数据"

【系统功能】
  - 工作台：数据总览、趋势图表、欠款排行
  - 记录管理：查看、搜索、筛选所有记录
  - 客户管理：查看每个客户的汇总和明细
  - 新增/编辑/删除：完整的数据管理
  - 导入/导出：Excel导入、CSV导出
